# Frontend · W Experiencias

SPA en React 19 + Vite + React Router, Tailwind CSS v4 y componentes estilo shadcn/ui (en `src/components/ui`).
Mapa con Leaflet / React-Leaflet. Ver el [README principal](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173 (proxy de /api y /media hacia el backend en :8000)
npm run build    # compila a dist/
npm run lint     # oxlint
```

Variables (`.env.example`): `VITE_API_URL`, `VITE_BACKEND_URL`, `VITE_TILE_URL`, `VITE_TILE_ATTRIBUTION`.
